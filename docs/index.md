# Lattice Documentation

The documentation is read at [lattice.build/docs](https://lattice.build/docs/). The site publishes
the Markdown in this directory, in `deploy/README.md`, and in the dependency
repositories at the versions `Package.resolved` pins. Edit the files here; the
footer of every page published from a repository names its source file.

Files here that the site does not publish are for contributors:
[development](development.md), [testing](testing.md),
[PR checklist](pr-checklist.md), [review template](review-template.md), and
[source of truth](source-of-truth.md).
